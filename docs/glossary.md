# Glossary

- **Example:** one row or item in a dataset.
- **Feature (X):** input information used to make a prediction.
- **Target (y):** value or class a supervised model learns to predict.
- **Model object:** a software object implementing an algorithm.
- **fit():** estimate learned model parameters from training data.
- **predict():** produce predictions for supplied inputs.
- **Train/test split:** keep examples aside to estimate performance on unseen data.
- **Metric:** a number summarizing one aspect of model performance.
- **Overfitting:** when a model fits training data well but generalizes poorly.
- **Tokenizer:** maps text to token IDs and may decode IDs back into text.
- **Configuration:** settings describing a model's architecture.
- **Checkpoint/weights:** saved learned parameter values.
- **Parameter:** a learned number, such as a neural-network weight.
- **Tensor:** a multidimensional array of numbers.
- **Forward pass:** calculation mapping input tensors to output tensors.
- **Logits:** unnormalized scores for possible next tokens.
- **Autoregressive generation:** repeatedly predict one token and feed it back as input.
- **Sampling:** choose a token randomly according to a probability distribution.
