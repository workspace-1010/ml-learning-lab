# Glossary

- **Feature (X):** input information used to make a prediction.
- **Target (y):** value or class a supervised model learns to predict.
- **Estimator/model:** object implementing learning or prediction methods.
- **fit():** learn model parameters from training data.
- **predict():** produce predictions from inputs.
- **Train/test split:** hold out examples to estimate performance on unseen data.
- **Parameter:** a value learned by a model, such as a neural-network weight.
- **Hyperparameter:** a setting chosen by the practitioner, such as tree depth.
- **Tokenizer:** converts text into token IDs and may decode IDs back into text.
- **Checkpoint/weights:** saved learned parameter values.
- **Embedding:** a vector representation of text or another item.
- **Chunk:** a smaller passage made from a longer document.
- **Retrieval:** selecting passages likely to be relevant to a query.
- **RAG:** retrieval-augmented generation; provide retrieved material to a language model as context.
